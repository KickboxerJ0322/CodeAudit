# セキュリティと公開前の条件

## 実装している対策

- Githubの公開リポジトリHTTPS URLだけを受付。API・アーカイブの接続先は固定ホストから生成し、リダイレクトは追従しない。
- 圧縮容量・展開後容量・展開ストリーム（PAXヘッダーを含む）・ファイル数・ファイルサイズ・時間を制限する。
- 絶対パス、親ディレクトリ参照、リンク、特殊ファイル、Windows特殊名、重複パスを拒否し、手動で対象ファイルだけを書き出す。
- コード、npm install、対象コードのビルド、Git hooks、リポジトリ内スクリプトは実行しない。
- 監査ごとの一時作業領域。ツールにはAPIキーを含まない環境を渡し、標準出力・標準エラーをログに残さない。時間・出力サイズを制限し、停止時に子プロセスを終了する。
- ツールの無視設定・リポジトリ内のSemgrepルールを採用しない。自作の信頼済みルールを使用する。
- Gitleaksの値は一時的にメモリでマスキングに使い、未マスクのJSONを削除する。レポートにはマスクした引用のみ保存する。
- AI入力のコード・コメント・前回要約は信頼しないデータとしてsystemInstructionで区別する。AIに外部ツールや外部URL取得権限を与えない。
- JSONスキーマ、全対象セグメント、実在ファイル、行範囲、コード引用を検証する。AI指摘のみでは確認された脆弱性としない。
- ID・閲覧トークンは暗号学的乱数。ハッシュのみ保存し、Authorizationで照合。存在しない・不正・期限切れは同じ404。
- 24時間を上限にAPIで失効を判定。起動中のSQLiteは定期削除。本番はFirestore TTLも設定する。
- 生IPを保存せずHMACで日次制限。全体の同時実行と予算予約を受付トランザクションで共有する。
- APIのno-store／nosniff／no-referrer、Reactの文字列エスケープ、固定GitHubリンク、Markdownの不信なテキストのエスケープ。

## 検査の限界と未完了条件

未検査のツール・非対応言語・除外ファイル・AI未分析・横断統合失敗・根拠不一致を表示する。全対象ファイルのAI処理と設定済みツールの実行が終わらなければcompletedにしない。completedもルールの網羅性や安全性を保証しない。

秘密のマスキングは既知パターンとGitleaks検出の範囲であり、すべての形式を完全には検出できない。未知の秘密形式や、悪意あるAI命令をモデルが絶対に無視することまでは保証しない。公開前に、AIプロバイダーのデータ利用条件と送信範囲を利用者に明示する。

通常終了・タイムアウト・キャンセル時は一時作業領域を削除する。OSによる強制終了ではfinallyが実行されない可能性がある。Cloud Run Jobsは一時ファイルをコンテナ終了とともに破棄する。ローカルでは起動時・定期処理で、監査時間上限＋60秒を超えた予約名の一時ディレクトリを清掃する。

IP制限は同一NATで共有され、IP変更で回避可能。Cloud Runの実際のプロキシ信頼境界を検証するまで受付を閉じる。ユーザーが送ったX-Forwarded-Forをそのまま採用しない。

費用上限は設定したモデル単価上限と最大出力に基づく保守的な予約。料金・モデル変更時は設定を確認する。Cloud RunやFirestore全体の費用は別途予算監視が必要。

## 本番公開前

Gemini実応答、Firestore競合とTTL、Cloud Run Job、IAMの最小権限、Secret Manager、WIF、Cloud Run client IP、実機UI、依存脆弱性、LGPLを含む配布noticeを実測・確認する。未検証事項はtesting.mdに記載する。GitHubへのpush・クラウド公開は明示的な指示後に行う。
