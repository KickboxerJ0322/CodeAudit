# CodeAudit

**公開GitHubリポジトリのコードをチェックし、問題の理由と直し方を日本語で説明する、無料のオンライン監査サービスです。**

👉 **[CodeAuditを開く](https://codeaudit-331230486346.asia-northeast1.run.app)**

ブラウザだけで利用できます。ログイン、ソフトのインストール、利用者自身のGemini APIキーの準備は不要です。スマートフォンからも使えます。

## 使い方

1. CodeAuditを開き、公開GitHubリポジトリのURLを入力します。
2. 監査を開始し、その画面を開いたまま待ちます。
3. 「GitHub取得 → 静的解析 → Gemini全体分析 → レポート生成」の進捗を確認します。
4. レポートで問題の内容、対象ファイル・行番号、根拠、修正方法を確認します。
5. 必要な結果をMarkdownまたはJSONで保存します。修正後は再監査して確認できます。

例えば、`https://github.com/KickboxerJ0322/rain-map` のように入力します。非公開リポジトリは対象外です。

**監査結果は24時間で閲覧できなくなります。** また、結果を見るための閲覧トークンをブラウザの永続保存領域に保存しないため、再読み込みすると閲覧資格を失います。必要なレポートは先に保存してください。「進捗サンプル」「結果サンプル」は架空のデータで、実際の監査ではありません。

## 何を調べるのか

「静的解析」は、対象コードを実行せずに、危険な書き方や設定を調べる方法です。CodeAuditは、専用ツールとAIを組み合わせています。

| 検査 | 主に調べること |
| --- | --- |
| Gitleaks | APIキー・パスワードなど、秘密情報らしい値の混入 |
| Semgrep | 入力値の扱いなど、危険につながるコードの書き方 |
| Trivy | 利用ライブラリの既知の脆弱性、Dockerなどの構成 |
| Gemini | 全対象ファイルの分割分析と、ファイル間の関係をまとめる横断統合 |

Geminiは一部のファイルを抜き出すだけではなく、**監査対象になった全テキストファイルを分割して分析し、最後に全体を統合**します。AIが挙げたファイル・行番号・引用を実在するコードと照合し、根拠が合わない指摘は除外します。除外ファイルや未検査の範囲もレポートに表示します。

## 追加調査と判断履歴

横断統合で不明点が残り、関連コードの再確認で判断できそうな指摘について、Geminiが追加調査を要求します。取得済み・マスク済みの対象ファイルから、指定された行だけを最大3回読み直します。1回最大3件の質問、質問ごとに最大3範囲、1範囲200行以内、合計24,000文字以内です。

例えば、HTML表示に渡る変数の生成元や、別ファイルの権限チェックを確認します。外部URL・任意のローカルファイルへのアクセス、コード実行、APIキーの試用は許可しません。対象指摘IDと読み取り範囲、引用の一致をサーバー側で検証します。不正な応答や未回答、追加調査の上限超過は部分監査として残し、完了扱いにしません。

レポートの「監査の判断履歴」に、質問・確認範囲・根拠に基づく判断を表示します。AI自身の指摘は根拠を照合した上で取り下げ可能ですが、静的解析の指摘をAI判断だけで削除しません。内部の思考過程を表示する機能ではありません。

「処理量・費用」では、対象行数、AI分析済みファイル数、所要時間、生成回数、追加調査回数、入力・出力トークン、推定API費用を確認できます。Markdown・JSONにも記録します。入出力の実測内訳が欠ける場合や、料金計算に対応していないモデルでは推定費用を算出しません。表示単価は3.5 Flash-Liteの標準テキスト料金で、実請求額やCloud Run等の費用、日次予算予約額とは別です。

追加調査も既存の64回・720,000トークン・4 USD・13分の上限に含めます。不要と判断した場合は追加のAI呼び出しを行いません。

## 約100ファイル・約1.5万行の監査実績

2026年10月11日の監査レポートで、次のリポジトリについて、静的解析・Gemini分析・横断統合の完了を確認しています。

| リポジトリ | 監査対象ファイル | 対象テキストの行数 | AI生成呼び出し | 記録トークン数 | 結果 |
| --- | ---: | ---: | ---: | ---: | --- |
| [SkyRoute](https://github.com/KickboxerJ0322/SkyRoute) | 98 | 15,945 | 18回 | 470,918 | 完了 |
| [TerminalBox](https://github.com/KickboxerJ0322/TerminalBox) | 111 | 14,201 | 17回 | 330,324 | 完了 |

**約100ファイル・約1.5万行のリポジトリを監査できた実績があります。** 行数はレポートの分割一覧から各ファイルの最大終了行を集計した値で、ソースコードだけでなくREADME、設定、依存関係のロックファイルなどを含みます。トークンはAIが扱う文章の細かな単位で、行数とは別の指標です。

これは当時のコミットに対する実績であり、現在のコードを再監査した結果ではありません。同じファイル数・行数でも、文章量、分割数、AI出力、処理時間によって完了できるかは変わります。画像・動画・3Dモデルなどの除外ファイルは、この全体分析の対象ではありません。

## 過去の監査で多かった指摘の具体例

以下はrain-map、CommentAgent、SkyRoute、TerminalBoxの過去のレポートで繰り返し見られた指摘です。現在も問題が残っているという意味ではありません。

| 指摘 | 初心者向けの説明 | 修正・確認の例 |
| --- | --- | --- |
| `innerHTML`への文字列の代入 | 外部から来た文字列をHTMLとして表示すると、不正なスクリプトを動かされる可能性があります（XSS）。SkyRouteやCommentAgentで複数の指摘がありました。 | 文字表示には`textContent`を使う。HTMLが必要なら入力経路・エスケープ・サニタイズを確認する。固定文字列だけなら、危険な外部入力が届くかを確認する。 |
| 依存ライブラリの既知の脆弱性 | 自分で書いたコード以外にも、利用している部品に既知の問題がある場合があります。レポートでは`qs`、`proxy-addr`、`uuid`などが指摘されました。 | 修正版へ更新し、ロックファイルを更新して互換性をテストする。その脆弱な機能を実際に利用しているかも確認する。 |
| Dockerfileの`HEALTHCHECK`不足 | コンテナ内のアプリが正常かを確認する設定が見つからない、という指摘です。複数リポジトリで見られました。 | Dockerfileだけでなく、Cloud Runの起動・稼働確認の設定も調べる。設定の不足が、そのまま悪用可能な脆弱性を意味するわけではありません。 |
| 秘密情報らしい文字列 | APIキーやパスワードに似た文字列がコード内に見つかった、という指摘です。TerminalBoxのレポートにもありました。 | 本物の秘密なら削除だけでなく失効・再発行する。教材の例やテスト用の値なら、実際に有効な秘密かを確認する。 |

レポートは「確認された問題」「設定確認が必要な問題」「セキュリティ改善の推奨事項」を分けます。ライブラリの脆弱性DBとの一致や秘密情報パターンとの一致は、実際に攻撃できることの証明ではありません。AI単独の指摘も、そのまま確定した脆弱性とは扱いません。

## Gemini 3.5 Flash-Liteを採用する理由と料金

現在のモデルIDは **`gemini-3.5-flash-lite`** です。大量のコードを読むため、API料金を抑えやすいモデルを採用しています。

以下は2026年10月11日に確認した、Gemini Developer APIの標準・テキスト料金です。出力には思考トークンも含みます。

| モデル | 入力100万トークン | 出力100万トークン |
| --- | ---: | ---: |
| **3.5 Flash-Lite（採用）** | **0.30 USD** | **2.50 USD** |
| 3.1 Pro Preview（1リクエストの入力20万トークン以下） | 2.00 USD | 12.00 USD |

同じトークン数なら、3.5 Flash-Liteの単価は上記Proの**入力で約85%、出力で約79%安く**なります。価格面で有利ですが、すべてのGeminiモデルの中で最安という意味ではありません。実際の監査品質やトークン消費はモデルによって変わります。

例えば、監査全体で入力60万・出力12万トークンを使用した場合、Gemini料金は約0.48 USDです。これは計算例であり、上の監査実績の実請求額ではありません。Cloud Runなどの運用費は別に発生します。

料金は変更されるため、[Google公式料金表](https://ai.google.dev/gemini-api/docs/pricing)を確認してください。

## 無料利用の上限

| 項目 | 現在の設定 |
| --- | --- |
| 利用回数 | 1接続元ネットワークあたり、日本時間で1日20回 |
| リポジトリ容量 | 20 MB |
| 対象ファイル数 | 最大2,000 |
| 1ファイル容量 | 最大512,000バイト |
| 監査処理の時間上限 | 13分 |
| サービス全体の同時監査 | 2件 |
| レポートの閲覧期限 | 24時間 |
| 1監査のAI累積トークン上限 | 720,000 |
| 1監査のAI生成呼び出し上限 | 64回（横断統合を含む） |
| 1監査のAI費用判定上限 | 4 USD |

回数は日本時間の午前0時に更新します。ログインを使わないため、回数はブラウザ単位ではなく、サーバーが識別する接続元ネットワーク単位です。同じ会社や家庭のネットワークでは上限を共有する場合があります。

**回数が残っていても、サービス全体の日次AI予算や同時実行上限に達すると受付が止まります。** 日次AI予算は通常80 USD、2026年10月11日のみ開発用の60 USDです。通常のCloud Run設定では3.60 USDずつ予約するため、サービス全体で1日最大22件の予算枠があります（同時実行などの条件は別です）。20回は回数上限であり、20回の受付を保証するものではありません。実際の上限・受付状態はホーム画面で確認できます。

費用判定は、AI呼び出し前に入力トークン数を数え、最大出力も含めて安全側に見積もります。Cloud Runでは100万トークンあたり5 USDの保守的な判定単価を使い、受付時に1監査3.60 USDを日次予算に予約します。**4 USDや3.60 USDは利用者への請求額でも、実際のGemini請求額でもありません。** 失敗した監査も予約額は返還しません。料金変更を自動追跡する機能はありません。

## 検査範囲と安全への配慮

- 取得したリポジトリのコード、インストールスクリプト、コンテナイメージを実行する監査ではありません。
- 公開性とコミットを確認して取得し、容量・時間・同時実行の上限を設けています。
- 秘密の値は可能な範囲でマスキングします。ただし、未知の形式の秘密まで完全に検出できる保証はありません。
- 閲覧トークンはURLやlocalStorageに保存しません。接続元IPはソルト付きHMACで扱い、生IPを保存しません。
- ツール失敗・AI未実行・上限超過・横断統合の失敗がある場合、全体監査を完了扱いにしません。
- Semgrepは同梱の7ルール（Python・JavaScript・TypeScript）です。すべての言語・危険パターンを網羅する検査ではありません。
- Gitleaksの対象は取得したコミットのファイルで、Git履歴は対象外です。Trivyは依存関係・構成を検査し、コンテナイメージ実体は検査しません。
- **監査完了や指摘ゼロは、安全性の完全な保証ではありません。** 動作中の認証・権限・ネットワーク設定などは別途確認が必要です。

## 開発・運用の仕組み

利用者はオンライン画面を開くだけです。開発・運用は次の構成です。

| 部分 | 役割 |
| --- | --- |
| React / TypeScript | 入力、進捗、日本語レポートの画面 |
| FastAPI / Cloud Run | 受付と結果閲覧のAPI |
| Cloud Run Jobs | 取得・静的解析・Gemini分析の監査処理 |
| Firestore | 本番の監査状態、結果、利用回数、予算予約の保存 |
| Secret Manager | APIキーなどの秘密情報の管理 |
| GitHub Actions / Cloud Build | テスト、ビルド、自動デプロイ |

mainへの更新でGitHub Actionsのテストが成功すると、自動デプロイが始まります。Cloud Buildが検証済みコミットを取得して再テストし、コミットSHAで固定したAPI・Workerイメージを配置します。手動デプロイも可能で、confirmationに`DEPLOY`の入力が必要です。Google Cloud認証はWorkload Identity Federationを使い、長期サービスアカウントキーは保存しません。

管理者用の日次制限リセットAPIは、強力な管理者トークンが設定されている場合にのみ利用できます。一般向け画面にリセットボタンはありません。リセットしても実際の請求は減らず、追加費用が発生し得ます。

詳しくは[設計](docs/architecture.md)、[セキュリティ](docs/security.md)、[デプロイ](docs/deployment.md)、[テスト](docs/testing.md)、[依存ライセンス](docs/dependencies.md)を参照してください。非公開リポジトリ、差分監査、自動PR、PDF、過去比較、TerminalBox API連携は未実装です。
